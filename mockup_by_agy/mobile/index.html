The mobile application follows a BottomNavigationBar with 5 primary root destinations. Modal flows and deep evidence use Drag-to-Dismiss Bottom Sheets to preserve user context.

Touch Target & Mobile Ergonomics

  • Minimum Touch Targets: All interactive buttons and tabs have an effective tap target of ≥ 44x44 points.
  • Safe Area Insets: Top safe area (44px on notch devices) and Bottom safe area (34px for home bar indicator).
  • Pull-to-Refresh: The Opportunity Brief and Company Analysis views support native swipe-down refresh to trigger backend completed session sync.

4 Mobile Design Archetypes

The mobile UI provides 4 switchable clean themes (accessible via the Sun icon in the top header or in the Settings tab):

1. Minimal iOS / SaaS: System SF Pro, clean slate `#F8FAFC`, rounded-14px cards, high clarity.
2. Swiss Editorial: Newsreader serif headlines, warm ivory `#FAF8F5`, formal paper memorandum feel.
3. Dark Institutional Pro: Obsidian `#090D16`, monospace data alignment, Bloomberg/Koyfin cockpit.
4. Bento Grid: Segmented modular cards, zinc `#F4F4F5`, pill chips.

APP-01: Opportunity Brief Rules

  • Decline Discovery Window: User can toggle Daily (≤ -2%) or 1-Month (≤ -8%). A stock must cross this threshold on completed sessions to appear.
  • Proxy Benchmark Label: When using a locally constructed equal-weight basket (e.g. IT proxy of 5 stocks), the UI must explicitly display Proxy Basket.
  • Conclusion Precedence: Evaluated in strict order:
    1. Fundamental concerns: Quality check failed or material concern verified.
    2. Insufficient evidence: Missing data, unverified corporate action distortion, or unreviewed sector.
    3. Watch and wait: Quality passes, but valuation fails or caution flag active.
    4. Worth researching: All quality checks pass, valuation < sector benchmark, and context verified.

APP-02: Company Analysis Rules

  • 3-Year Statement Evidence: Revenue, PAT, Operating Cash Flow, Capex, and derived Free Cash Flow (FCF = OCF − Capex) with consolidated basis.
  • Corporate Action Protection: Splits and bonus issues must not trigger apparent collapse. Unverified corporate actions mark candidate Insufficient Evidence.
  • Missing Value Rule: Unavailable inputs show "Unavailable" (never 0, never silent pass).

Local SQLite Storage Entities

All watchlist entries, user thesis notes, and research review intervals must persist locally on the device: 

CREATE TABLE watchlist (
  isin TEXT PRIMARY KEY,
  ticker TEXT NOT NULL,
  added_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE personal_notes (
  isin TEXT PRIMARY KEY,
  thesis TEXT,
  concerns TEXT,
  next_review_date DATE,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (isin) REFERENCES watchlist(isin)
);

CREATE TABLE sector_research_notes (
  sector_id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  source_url TEXT NOT NULL,
  published_date DATE,
  reviewed_date DATE,
  next_review_date DATE,
  classification TEXT CHECK(classification IN ('temporary', 'structural', 'mixed', 'unknown')),
  severity TEXT CHECK(severity IN ('informational', 'caution', 'material')),
  summary TEXT
);
